# Создание репозитория
1 шаг: создаём на GitHub новый репозиторий \
2 шаг: инициализируем наш репозиторий локально через консоль командой **git init** \
3 шаг:  затем командой **git add .** добавляет все существующие файлы в индекс\
![[Pasted image 20261011225816.png|211]]
4 шаг: после выполняем первый коммит командой **git commit -m "message"** \
5 шаг: пишем команду для подключения к репозиторию \
**git remote add origin https://github.com/ТВОЙ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git** \
6 шаг: проверяем что находимся в главной ветке **Main(Master)** \
7 шаг: заливаем проект на GitHub командой **git push -u origin main** \
Теперь при добавлении файлов алгоритм следующий: \
	- добавляем их (**git add .**)
	- коммитим их (**git commit -m "message"**)
	- пушим их (**git push -u origin <имя ветки/новая ветка>**)
# Как работать
клонируется репозиторий с помощью команды **git clone** \
посмотреть существующие ветки можно командой **git branch -a** \
теперь зная название ветки, используем команду **git checkout <имя ветки>** и переключаемся в эту ветку \
далее с помощью команды **git pull origin <имя ветки>** синхронизируем изменения \
и уже потом создаём свою ветку **git checkout -b <имя ветки/новая ветка>** \
если над фичей работают несколько человек, и нужно подтянуть изменения используем команду **git pull** \
# Закончили работу (pull request)
Подытоживаем:
	1 клонируем репозиторий
	2 работаем в своей ветке
	3 создаем **pull/merge request**
	4 ждем одобрения
если всё хорошо, то изменения вливаются в основную ветку через **merge** или **rebase** 
в чем разница **merge/rebase**
![[Pasted image 20261011231848.png|244]]     ![[Pasted image 20261011231915.png|241]]

ВАЖНО
**rebase НЕЛЬЗЯ** делать для веток, которые использует кто-то еще, иначе возникнут проблемы с историей

если нужно взять какой-то полезный коммит, но не тянуть туда всю ветку используют команду **git cherry-pick**
###### плюсы:
	быстрый перенос
	изменения в нужную ветку
###### минусы:
	 теряется контекст
	 дублирование кода и лишние конфликты

| **Команда** | **Что делает**                        |
| ----------- | ------------------------------------- |
| git init    | Инициализировать репозиторий          |
| git add     | Добавить файлы для следующего коммита |
| git commit  | Зафиксировать изменения               |
| git push    | Отправить коммиты в репозиторий       |
| git pull    | Забрать изменения из репозитория      |
